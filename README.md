# 📝 To-Do List App

A simple command-line To-Do List application built using Python.

## ✨ Features

- ➕ Add tasks
- 📋 View tasks
- ❌ Remove tasks
- 🚪 Exit the application
- ⚠️ Handles invalid task numbers

## 🛠️ Technologies Used

- Python

## ▶️ How to Run

1. Make sure Python is installed.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python todo.py
```

5. Follow the instructions shown in the terminal.
